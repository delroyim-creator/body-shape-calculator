# ACG Body Shape Calculator

A responsive body shape calculator built with **HTML, CSS, and vanilla JavaScript**.

Users enter shoulder, bust, waist, and hip measurements. The calculator applies ratio-based logic to classify the result as one of five body shapes and displays personalized styling suggestions.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- DOM manipulation
- Form validation

## Features

- Four measurement inputs with validation feedback
- Dynamic body-shape classification
- Five possible body-shape results
- Personalized feature summaries
- Recommended styles and styles to avoid
- Responsive desktop and mobile layout
- Inline SVG result icons

## Body Shapes

- Hourglass
- Pear
- Apple
- Inverted Triangle
- Rectangle
